# Available PD-day extension reference (no tool changes)

The September 2026 **Tiered Task Tool** is available as a design reference for Algebra 1 extensions and Smarty Pants tasks.

GitHub source (read-only for this workflow): `https://github.com/tnezki/memories/tree/main/district_tools/tiered_task_tool/`

Key existing files:
- `TIERED_TASK_GENERATION_CONTRACT.md` - depth-of-knowledge progression and evidence expectations.
- `README.md` - teacher workflow and source attachment support.
- `index.html` / `app.js` - grade-level, I Can, reading/access, product-choice, and time controls.

Its **DOK 1-4** rule describes cognitive complexity rather than simply harder arithmetic. Borrow its reasoning framework for short warm-up extensions, assessment applications and longer Smarty Pants challenges, but **do not force a complete DOK 1-4 task card into a short EX/YTI, Quick Check or warm-up**. Do not copy the PDF/page layout as the Algebra 1 student lesson style. The existing Algebra 1 V7 style, bank provenance and teacher-review rules remain authoritative.

This record documents availability only. The Tiered Task Tool was **not modified**, and it was **not automatically integrated** into the Algebra 1 application.
