# Algebra 1 Modified Lesson — student style reference (November 21, 2026, v7)

**Purpose:** Retain the latest teacher-reviewed HTML/CSS prototype as a reusable style reference for the future Modified Lesson Builder. **This package does not install or replace the live CPM Tools app or its warm-up question bank.**

## What is preserved
- Four CSS files: `01-tokens.css`, `02-lesson.css`, `03-print.css`, `04-assembler.css`.
- `lesson_reference.html`: an offline interactive student preview whose four stylesheets are loaded relatively from the local `css/` directory. MathJax is embedded in the HTML; answer popups are part of the reference. It is not a prebuilt yearlong lesson.
- `assets/diamond_m48_p2.png`: **actual current Algebra 1 warmup_bank Graph Tool PNG** (source-backed), replacing the provisional hand-drawn SVG in the warm-up. The prototype's one diamond is product -48, sum +2, missing sides +8 and -6.
- `diamond_qa.json`: recorded arithmetic and metadata verification for all 306 draft fluency diamond instances in the connected warm-up bank.

## Student design choices to preserve
- Compact 3.2.3 section headings; blue-tinted section headings and selective thick left blue border.
- No name/date fields on student pages; students normally work in Notability. Exit ticket printed separately may include a name field.
- Open writing space (no unnecessary ruled lines or oversized writing boxes).
- On regular days: warm-up page 1 offers Q1 linear/quadratic and Q2 diamond/factor; page 2 Q3/Q4; page 3 optional Q5/Q6.
- Q1/Q2 choices have no I-can text, but one solution trigger for each of the four choices.
- Q3–Q6 use purposeful I-can statements before numbered question text where appropriate.
- MathJax equations sized consistently with surrounding body text.
- EX/YTI stacked when parallel columns are too cramped.
- One shared practice set across formats; Projection Sets display two questions per page and answer trigger inside each blue I-can band.
- Smarty Pants answer trigger in its blue activity-title band.
- Printed reflection/exit ticket is simple black-and-white, two tickets per page; confidence + choose one of four broad 3-minute reflection prompts. No additional math task required.
